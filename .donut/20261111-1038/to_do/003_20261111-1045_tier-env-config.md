# Tier targets configured by THRIFT_* env, with a fully-local option

Today the tiers are hard-wired to Bedrock env vars. Let each tier point at any LiteLLM model string, including local Ollama models, so "completely local" is a config choice.

**Slug:** tier-env-config
**Depends on:** None
**Verify:** `.venv/bin/python -c "import yaml,sys; d=yaml.safe_load(open('config.yaml')); assert all('THRIFT_' in m['litellm_params']['model'] for m in d['model_list']); print('ok')"`

## Goal
`config.yaml` reads `THRIFT_SIMPLE`, `THRIFT_MODERATE`, `THRIFT_HARD` (full LiteLLM model strings such as `bedrock/us.anthropic.<id>` or `ollama_chat/qwen3:8b`), and `.env.example` documents both a Bedrock and an all-local example.

## Context
- `config.yaml` lines: three `model_list` entries using `os.environ/BEDROCK_*` plus an `auto` placeholder using `BEDROCK_MODERATE`; `callbacks: hook.router`.
- `.env.example` has `BEDROCK_*` placeholders, `AWS_PROFILE`, `AWS_REGION_NAME`, `LITELLM_MASTER_KEY`.
- LiteLLM Ollama strings use the `ollama_chat/<model>` prefix; the Ollama base URL comes from `OLLAMA_API_BASE` (default http://localhost:11434). Verify against the installed litellm (`.venv/bin/python -c "import litellm;print(litellm.__version__)"`, docs in site-packages) before writing the example.

## Preflight
`grep -n BEDROCK config.yaml .env.example` shows the old names.

## Files
- Modify: `config.yaml`, `.env.example`
- Do not touch: `.env` (user's secrets), `hook.py`, `README.md` (a later ticket)

## Requirements
1. Rename `BEDROCK_SIMPLE/MODERATE/HARD` to `THRIFT_SIMPLE/MODERATE/HARD` in both files; `auto` uses `THRIFT_MODERATE`.
2. `.env.example` has a commented "Bedrock" block and a commented "All local (Ollama)" block, each a complete working set; AWS vars only in the Bedrock block.
3. The existing `.env` is NOT edited; the worker notes in Open issues that the user must rename keys locally.

## Testing
The Verify command above; `grep -rn BEDROCK config.yaml .env.example` returns nothing.
