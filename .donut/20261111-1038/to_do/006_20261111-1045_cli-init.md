# `thrift init`: write .env and print next steps

**Slug:** cli-init
**Depends on:** `cli-doctor`
**Verify:** `.venv/bin/python -m unittest tests.test_init -q`

## Goal
`thrift init [--local | --bedrock]` creates `.env` from `.env.example` with a generated `LITELLM_MASTER_KEY`, never overwriting an existing `.env`, then runs `doctor`.

## Context
- `.env.example` (after `tier-env-config`) holds commented Bedrock and all-local blocks. `.env` is gitignored.
- Local preset: `THRIFT_SIMPLE/MODERATE/HARD` = `ollama_chat/<model>`; use three env-less defaults the worker takes from the all-local example in `.env.example` (do not invent new model names).
- Bedrock preset: leave the `bedrock/...` IDs as placeholders and print which to fill in.

## Preflight
`ls .env.example`; `thrift doctor` runs.

## Files
- Modify: `thrift/cli.py`
- Create: `tests/test_init.py`
- Do not touch: the real `.env` (tests use a temp cwd)

## Requirements
1. If `.env` exists: print "`.env` exists, leaving it" and skip writing.
2. Master key is `"sk-" + secrets.token_hex(16)`.
3. The chosen preset block is uncommented in the output; the other block is dropped. Default is `--local`.
4. Finishes by calling doctor and printing `thrift serve` as the next step.

## Testing
unittest in a temp dir with a copied `.env.example`: `init --local` makes `.env` with an `sk-` key and `ollama_chat/` targets, no `bedrock/`; second run leaves the file byte-identical.
