# `thrift serve` replaces run.sh

One command starts the router proxy.

**Slug:** cli-serve
**Depends on:** `cli-route`, `tier-env-config`
**Verify:** `.venv/bin/python -m unittest tests.test_serve -q`

## Goal
`thrift serve [--port 4000] [--host 127.0.0.1]` loads `.env` and runs LiteLLM with the repo's `config.yaml`, and works from any directory once installed.

## Context
- `run.sh` does `set -a; . ./.env; exec .venv/bin/litellm --config config.yaml --host 127.0.0.1 --port 4000`. `config.yaml` references `callbacks: hook.router`, so `hook.py` must be importable: LiteLLM imports it relative to the config dir.
- `.env` contains `LITELLM_MASTER_KEY`. `python-dotenv` is already installed as a litellm dependency (`.venv/bin/dotenv`).
- Config/hook location after `pip install` is not the repo: keep it simple by resolving `--config` (default `./config.yaml`, else `$THRIFT_HOME/config.yaml`); if neither exists, exit 2 with a message pointing at `thrift init`.

## Preflight
`thrift/cli.py` has an argparse `main` with a `route` subcommand; `ls config.yaml hook.py` succeeds.

## Files
- Modify: `thrift/cli.py`; Delete: `run.sh`
- Create: `tests/test_serve.py`
- Do not touch: `config.yaml`, `hook.py`

## Requirements
1. `serve` calls `dotenv.load_dotenv(".env")` (does not override existing env), builds `[sys.executable, "-m", "litellm", "--config", cfg, "--host", h, "--port", p]` and `os.execvp`s it.
2. Missing config -> exit code 2, message on stderr.
3. Missing `LITELLM_MASTER_KEY` -> warn on stderr but continue.

## Testing
unittest patches `os.execvp` and asserts argv and that missing config exits 2 (use a temp cwd). Manual: `thrift serve`, then `curl -s localhost:4000/health/liveliness`.

## Acceptance criteria
- [ ] Tests pass; `run.sh` removed and no remaining references (`grep -rn run.sh . --include=*.md --include=*.py --exclude-dir=.venv`)

## Out of scope
Daemonizing, launchd, log files.
