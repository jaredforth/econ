# Packaging and a `thrift route` command

Make the project installable with one command and give it a CLI entry point, starting with a dry-run router.

**Slug:** cli-route
**Depends on:** `extract-classifier`
**Verify:** `.venv/bin/python -m unittest tests.test_cli -q`

## Goal
`thrift route "prompt"` prints the chosen tier and target model (and nothing else on stdout) using the local Ollama classifier. Installable via `uv tool install .` / `uv pip install -e .`.

## Context
- No `pyproject.toml` exists. Current deps (installed in `.venv`): `litellm[proxy]`, `httpx`. `laya`/`anthropic` belong only to the legacy `router.py`/`fit.py` path and must NOT be dependencies.
- Tier→model mapping today is in `config.yaml` via env `BEDROCK_SIMPLE/MODERATE/HARD`; a later ticket renames these. For now `route` prints the tier name and, if `BEDROCK_<TIER>` is set, that value.
- `thrift.classify.pick_tier` (async) and `TIERS` exist after `extract-classifier`.

## Preflight
`.venv/bin/python -c "from thrift.classify import pick_tier, TIERS"` succeeds. `ls pyproject.toml` fails.

## Files
- Create: `pyproject.toml`, `thrift/cli.py`, `tests/test_cli.py`
- Do not touch: `hook.py`, `config.yaml`, `router.py`

## Requirements
1. `pyproject.toml`: name `thrift`, requires-python `>=3.10`, deps `litellm[proxy]`, `httpx`; `[project.scripts] thrift = "thrift.cli:main"`; setuptools packages `["thrift"]`.
2. `thrift.cli.main(argv=None)` uses stdlib `argparse` with subcommands (future tickets add more). `route PROMPT`: reads stdin when PROMPT is `-`; prints `<tier>` on the first stdout line, then the target model on a second line if known.
3. Exit code 0 even when Ollama is down (the classifier falls back to `moderate`); no warning is needed in this ticket.

## Implementation steps
`main` builds the parser, dispatches `args.fn(args)`. `route` does `asyncio.run(pick_tier(text))`. Entry: `if __name__ == "__main__": main()`.

## Testing
unittest: monkeypatch `thrift.cli.pick_tier` with an async stub returning "hard"; `main(["route","hi"])` stdout first line is `hard`; `main(["route","-"])` with patched `sys.stdin` works. Expected `OK`. Manual: `uv pip install -e . && thrift route "rename this var"` (needs `ollama serve`).
