# `thrift env` for Claude Code, and `thrift bench` wrapper

**Slug:** cli-env-bench
**Depends on:** `cli-serve`
**Verify:** `.venv/bin/python -m unittest tests.test_env -q`

## Goal
`thrift env` prints shell exports that point Claude Code at the router. `thrift bench MODEL...` runs the existing accuracy/latency benchmark so the router model can be chosen from data.

## Context
- README: for Claude Code use `ANTHROPIC_BASE_URL=http://127.0.0.1:4000`, `ANTHROPIC_AUTH_TOKEN=<LITELLM_MASTER_KEY>`, and requests must send `model="auto"`, so also `ANTHROPIC_MODEL=auto`. Use eval-able output: `eval "$(thrift env)"`.
- `bench.py` runs at import time (loops over `sys.argv[1:]`, reads `labels.csv`, `hook.ROUTER_MODEL`). After `extract-classifier` it uses `thrift.classify`. Wrap it: move its body into `thrift/bench.py` `def run(models)` and make `bench.py` delete (or a 3-line shim).

## Requirements
1. `thrift env [--port 4000]` prints three `export` lines; key from `LITELLM_MASTER_KEY` (load `.env`), exits 2 if unset.
2. `thrift bench MODEL...` calls `thrift.bench.run`; if `labels.csv` is missing print "run build_labels.py first" and exit 2.
3. Bench output format is unchanged.
